# 📥 Bước 1: Tải dữ liệu

Tải bộ dữ liệu [Vietnamese Legal Documents](https://huggingface.co/datasets/th1nhng0/vietnamese-legal-documents) (~518,000 văn bản) từ HuggingFace về `data/raw/`.

## Cài đặt

```bash
pip install -r requirements.txt
```

## Chạy

```bash
python download_data.py
```

Dữ liệu sẽ được tải vào: `data/raw/vietnamese-legal-documents/`
